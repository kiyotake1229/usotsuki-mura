現状です。Web 版は GitHub Pages で公開していて、ホーム画面に追加すれば通信なしでも遊べます。iOS アプリは Capacitor で作り、GitHub の macOS 環境でシミュレータ向けと実機向けの両方のビルドが通っています。App Store 用のスクリーンショットと申請文面の下書きも用意してあります。記録や操作の内容は外に送らず、記録は端末の中だけです。残っているのは、スマホ実機での確認と Apple への申請です。
