## 1. 1分版（エレベーターピッチ）

> 毎朝1件、事件が届く推理パズルです。村人は「正直者」か「嘘つき」のどちらか。証言から見分けて、犯人を1人当てます。知識も反射神経もいらない、筋道だけで解けるパズルです。1回3〜5分。
>
> 問題は**全部プログラムがその場で作っています**。出す前に「答えが1つに決まるか」を総当たりで確かめ、「当てずっぽうなしで順に考えれば解けるか」をプログラムが実際に解いて確かめています。同じ日なら全員同じ問題。曜日で難しさが変わり、練習と容疑者9人の難問もあります。
>
> 連続日数・称号・結果の共有画像で、毎日開く理由を作りました。記録は端末の中だけで、外には送りません。
>
> Web版は公開済み。**iOS はビルドが通るところまで確認済み**で、申請文面の下書きもあります。残りは実機確認と Apple Developer の登録。あと、決めていただきたいことが2つあります。

### 2-1. 何のアプリか・ねらい（30秒）

- 毎朝1件届く、日替わりの推理パズル。村人の証言から正直者と嘘つきを見分け、犯人を1人当てる
- ねらいは「思考力を問う」。知識も反射神経もいらず、筋道だけで解ける。1回3〜5分で、答えは必ず1つ
- 同じ日なら全員同じ問題。日付から作るので、サーバーはいらない
- Web版は公開中、iOS はビルド確認まで済み

### 2-2. 遊び方と考え方（1分）※例題をたどる

**スライド 03（20秒）**
> 「決まりは単純です。村人は正直者か嘘つき。正直者は本当のことしか言わない、嘘つきはウソしか言わない。1人1つ証言して、犯人はちょうど1人。犯人が正直者のこともあります」
> 「例題の4人です。アオイ『犯人はエマだよ』、イツキ『犯人は嘘つきだ』、ウタ『エマは正直者よ』、エマ『イツキは正直者なんだ』」

**スライド 04（40秒）**
> 「コツは、1人を仮に決めて、食い違いを探すことです」
> 「もしイツキが嘘つきなら、エマの『イツキは正直者』はウソなのでエマも嘘つき。するとウタの『エマは正直者』もウソで、ウタも嘘つき。イツキの『犯人は嘘つき』がウソなので犯人は正直者で、残るのはアオイ。でも正直者のアオイが『犯人はエマ』と言っている。食い違います」
> 「だからイツキは正直者。そこから一本道で、エマもウタも正直者。イツキの言うとおり犯人は嘘つきなので、アオイ。答えは、アオイだけが嘘つきで、犯人もアオイです」
> 「当てずっぽうはいりません。この考え方で最後まで解ける問題だけを出しています」

### 2-3. デモ（2分）※台本

**① 今日の事件を開く（15秒）**
> （ホーム画面のアイコンから開く）「ホームに今日の事件が出ています。番号、★、容疑者の人数、題名。曜日で難しさが変わって、月曜がいちばんやさしく、土日が★3です」
> 「iOS 版では、毎朝決めた時刻に『今日の事件が届きました』と通知が来ます」（［今日の事件を開く］）

**② 判子を押す（20秒）**
> 「あらましの下に村人のカードが並びます。吹き出しが証言です。村長のメモがある日は、それが必ず本当で、入口になります」
> 「カードに『正直者』『嘘つき』の判子を押して、犯人だと思う1人に『犯人』。もう一度押せば消えます」（何人かに押す）
> 「証言の中の名前を押すと、その人のカードに飛びます」

**③ わざと1回間違える（30秒）※必ず見せる**
> （全員に判子を押し、犯人だけわざと別の人にして［推理を提出］）「わざと違う人を犯人にして出してみます」
> 「間違えると、食い違っている証言のカードが赤くなって、理由を文で教えてくれます。『あなたの推理では……。でもその場合、……はウソになってしまう』。ただの不正解ではなく、**どこがおかしいか**が分かる。ここがこのアプリらしいところです」
> 「ミスが1つ増えて、提出の記録に□が付きます。同じ答えのままでは出し直せません」
> 「困ったときは［ヒント］。1段目は考える場所だけ、2段目で次の一手を教えます」（押さずに説明だけ）

**④ 解く → 解決の判子（15秒）**
> （犯人を直して［推理を提出］）「正解すると、大きな『解決』の判子が押されます」
> 「時間・ミス・ヒント、提出の記録、連続日数。称号は、ノーミス・ノーヒントなら名探偵。今日は1回間違えたので『粘りの調査係』です」

**⑤ 解説（10秒）**
> （［解説を見る］）「考える順番どおりに手順が並びます。仮定を使う所は箱で囲ってあって、さっきの例題と同じ考え方です」

**⑥ 共有画像（15秒）**
> （［事件に戻る］→［結果を見る］→［画像で共有］）「結果を1枚の画像にして、スマホの共有画面から送れます。**答えと村人の名前は描かない**ので、ネタバレになりません。全員同じ問題なので、『何回目で解けたか』を比べられます」

**⑦ 練習の難問（15秒）**
> （共有を閉じて［ホームへ］→ 練習の［難問］）「練習は★1〜★3 を何問でも。いちばん下が容疑者9人の難問です」
> 「9人でも、その場で作って答えが1つか確かめています。カードを詰めて、上に名簿。名前を押すとその人のカードへ飛びます。腰を据えて解く用で、1問5〜10分くらいです」（解かずに戻る）

**⑧ 機内モード（時間があれば・10秒）**
> （機内モードにして、ホーム画面から開き直す）「このまま遊べます。記録はこの端末の中だけです」

### 2-4. 問題の作り方と品質（30秒）

- 問題は人が作っていない。毎回プログラムが作る
  1. 先に正解（だれが正直者で、だれが犯人か）を決める
  2. その答えに合うように、1人ずつ証言を割り当てる
  3. 答えが1つか、全部の組み合わせを総当たりで確かめる
  4. 人の考え方をまねたエンジンで実際に解き、最後まで解けるか・★いくつかを判定する。合わなければ捨てて作り直す
- 自動テスト全64項目すべて合格。テストはエンジンとは別に、自分で総当たりして答えと解説の各手順を検算する
- 9人に広げたとき、今までの3〜6人の問題が1つも変わっていないことを24,260件で照合した（違い0件）。遊んでいる人の問題を途中で変えない

### 2-5. 現状（30秒）

- Web版 公開中（GitHub Pages）。PWA 対応（ホーム画面に追加でき、一度開けば通信なしで遊べる）
- iOS プロジェクト作成済み（Capacitor 7、Bundle ID `work.ltv.usotsuki`）。手元に Xcode が無いので、GitHub Actions のクラウドの Mac でビルドし、シミュレータ向け・実機向け（署名なし）とも成功
- ネイティブ機能: 毎朝の通知（時刻を選べる）と夜の念押し、触覚、共有シート、記録の二重保存
- App Store 用スクリーンショット（3サイズ×6枚）、申請文面の下書き、サポートページ（プライバシーポリシー）も用意済み
- **未確認**: スマホ実機での動作（iPhone・Android）と、Xcode での実機ビルド。先に自分から言う

### 2-6. 次のステップとお願い（30秒）

- ① 実機確認（清武）: iPhone・Android で、戻るスワイプ・画像の共有・ホーム画面に追加・オフライン
- ② Apple Developer Program の登録（年12,800円。加入状況は未確認）
- ③ Xcode で署名・申請（岩崎さん）: `ios-app/岩崎さんへの引き渡し手順.md` のとおり。通知・触覚は、ここで実機で確かめる
- 費用は Apple Developer Program だけ。GitHub は無料の範囲で、素材の購入も無い
- **決めていただきたいこと**:
  1. 問い合わせ用のメールアドレス（今は GitHub の Issues だけ。審査に備えてサポートページに載せたい）
  2. リポジトリを公開のままでよいか（開発の記録と引き渡し手順も入っている。公開サイトでは隠しているが、GitHub 上では読める）

## 3. 想定質問と答え

| 質問 | 答え |
|---|---|
| 問題が尽きない？ | 日付からその場で作るので、毎日新しい問題が出る（同じ日なら全員同じ）。練習と難問は何問でも作れる。事件の題名は53件を回していて、同じ題名はおよそ1か月あくが、村人と証言はその日ごとに別。約3年分（1,100日）の日替わりを作って、テストが全部通ることも確かめた |
| 答えが間違っていない？ | 出す前に、全部の組み合わせを総当たりして答えが1つだけか確かめる。2つ以上あれば出さない。さらに人の考え方をまねたエンジンで実際に解き、最後まで解けたものだけ出す。自動テスト（全64項目）は、エンジンとは別に自分で総当たりして、答えと解説の各手順を検算している。9人の難問も解説を見ずに3問解いてみて、3問ともエンジンの答えと一致した |
| 難しすぎない？ | 曜日で難しさを変えている。月・火は★1で、村長のメモから順にたどれば解ける（仮定はいらない）。困ったら2段階のヒント。間違えるとどの証言と食い違うかを教えてくれて、解いたあとは考える順番どおりの解説が読める |
| ほかの脳トレとの違いは？ | ほかのアプリと比べる調査はしていない。このアプリで言えるのは3点。知識も反射神経もいらず筋道だけで解ける。毎日違う問題をプログラムが作り、答えが1つで順に解けることを確かめてから出している。間違えたとき「どこが食い違うか」を教え、解説で考え方まで分かる |
| 通信や個人情報は？ | 記録は端末の中だけ。記録や操作の内容を外に送る処理は無い。外から読むのは表示用の書体（Google Fonts）だけで、読めなくても端末の文字で動く。アカウント・広告・解析なし。App Store のプライバシーは「データを収集しません」。気になるなら、書体をアプリに入れて通信を完全になくす改修もできる（今後の候補） |
| 費用は？ | Apple Developer Program（年12,800円）だけ。加入状況は未確認。公開（GitHub Pages）とビルド確認（GitHub Actions）は無料の範囲。絵・似顔絵・判子はすべてコードで描いた SVG、効果音もその場で作る音で、素材の購入は無い |
| 審査4.2（WebViewだけのアプリ）は？ | 完全オフラインで動き、問題は端末の中のエンジンが作る（サーバーから取ってこない）。記録は端末内で、毎日続ける設計（連続日数・事件簿）。ネイティブ機能として毎朝の通知・夜の念押し・触覚・共有シートを入れた。備考欄に貼る英文も手順書に用意。ログイン不要で、審査の日が★3でもヒントを押せば解ける |
| iOS で本当に動く？ | クラウドの Mac（GitHub Actions）で、シミュレータ向け・実機向けのビルドは成功。実機での動作（通知・触覚・共有シート）はまだ確かめていない。Xcode で動かすときに確かめる |
| 9人の問題は重くない？ | 作るのは平均5.5ミリ秒（開発用の Mac）。スマホが数倍遅くても0.1秒以下の見込み。別の処理（Web Worker）で作るので、待つ間も画面は止まらない |
| 共有でネタバレしない？ | 共有画像には答え（犯人・だれが嘘つきか）と村人の名前を描かない。出るのは事件名・★・称号・時間・ミス・提出の記録・連続日数 |
| データは消えない？機種変更は？ | iOS アプリは WebView の保存とネイティブの保存に二重に書き、片方が消えても戻す。機種変更での引き継ぎ（記録の書き出し・読み込み）はまだ無い。今後の候補 |
| 年齢制限は？ | 4+。事件は「羊が消えた」「帽子がさかさま」など、のどかな村のいたずらだけ |
| Android は？ | Web版をホーム画面に追加すれば、アプリのように使える（PWA）。Android の実機確認はまだ |
| リポジトリはなぜ公開？ | 兄弟アプリ（goi-dojo・maze-puzzle など）と同じ形にした。公開サイトでは開発の記録・手順書を隠しているが、GitHub 上では読める。GitHub Actions が無料なのは公開リポジトリの場合。非公開にするかは決めていただきたい |

## 4. 話し方のコツ

- 最初の30秒で「問題はプログラムが作り、答えが1つか確かめてから出す」「Web は公開済み・iOS はビルド確認まで」「記録は端末の中だけ」の3点を言い切る
- 例題（スライド 04）は指でたどりながらゆっくり。ここが伝わるとデモが早い
- デモは**実際に解く**。わざと1回間違えて「食い違い」の表示を見せる。ここと「解決」の判子が見せ場
- 「通信なし」とは言い切らない。「遊ぶのに通信はいらない」「記録や操作の内容は外に送らない」と言う（書体だけは外から読む）
- 数字は3つまで（1回3〜5分／自動テスト64項目／容疑者9人）。多く言わない
- 実機での確認がまだなことは、先に自分から言う
- 最後は「決めていただきたいこと」2つを具体的に言って終わる
