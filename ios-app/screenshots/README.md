# App Store 用スクリーンショット

App Store Connect の「iPhone」のスクリーンショット欄に、フォルダごとにファイル名の番号の順でアップロードする。
透明なしの PNG。2026-10-08 にアプリの画面をそのまま撮った（記録の数字は見本）。

| フォルダ | 大きさ（横×縦 px） | 入れる欄 |
|---|---|---|
| `6.7/` | 1290 × 2796 | 6.9インチ（または 6.7インチ）ディスプレイ |
| `6.5/` | 1242 × 2688 | 6.5インチディスプレイ |
| `5.5/` | 1242 × 2208 | 5.5インチディスプレイ |

| 番号 | 画面 |
|---|---|
| 1-home | ホーム（今日の事件・連続日数・練習） |
| 2-board | 事件の画面（判子を押したところ） |
| 3-result | 結果（「解決」の大きな判子・称号） |
| 4-hint | ヒントの2段目（次の一手） |
| 5-explain | 解説（考える順番どおりの手順） |
| 6-hard-dark | 容疑者9人の難問（ダークテーマ） |

撮り方: Google Chrome の画面なしモードで `http://127.0.0.1:8793/` を開き、画面の大きさを 430×932（6.7）・414×896（6.5）・414×736（5.5）、拡大率3倍にして撮った（音は消してから操作）。画面を大きく変えたときは撮り直す。
