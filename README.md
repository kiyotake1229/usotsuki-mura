# 嘘つき村の事件簿

毎朝1件の事件が届く、日替わりの推理パズル。村人の証言から「正直者」と「嘘つき」を見分け、犯人を1人当てる。スマホ縦持ち・片手・1回3〜5分を想定した単一HTMLアプリ。
問題はすべてプログラムがその場で作り、「答えが1つに決まる」「当てずっぽうなしで順に考えれば解ける」ことをプログラムで確かめてから出している。

## 遊び方の要点

- 村人は「正直者（本当のことしか言わない）」か「嘘つき（ウソしか言わない）」のどちらか。1人1つずつ証言する
- 犯人はちょうど1人。犯人が正直者のこともある
- 「村長のメモ」がある日は、そのメモは必ず本当（入口の手がかり）
- 「同じ側」＝2人とも正直者か2人とも嘘つき。「違う側」＝片方が正直者で片方が嘘つき
- 村人カードに「正」「嘘」の判子を押し、犯人だと思う1人に「犯」の判子を押す。もう一度押すと消える
- 全員の判定と犯人がそろうと「推理を提出」が押せる。違っていれば、どの証言と食い違うかを赤く示して教えてくれる（ミス+1）
- 困ったら「ヒント」。1段目は「どこを考えるか」、2段目は「次の一手」そのもの（仮定の一手は、わかることを先に1行で見せる）
- 解いたあとは「解説」で、考える順番どおりの手順を読める

## 主な機能

- 日替わりの事件: 2026-10-01 を No.1 とした通し番号。端末の日付で決まり、同じ日なら全員同じ問題。曜日で難しさと人数が変わる

  | 曜日 | 月 | 火 | 水 | 木 | 金 | 土 | 日 |
  |---|---|---|---|---|---|---|---|
  | 難しさ | ★1 | ★1 | ★2 | ★2 | ★2 | ★3 | ★3 |
  | 容疑者 | 4人 | 5人 | 4人 | 5人 | 6人 | 5人 | 6人 |

- 練習: ★1〜★3 を何問でも（日替わりの記録とは別）。途中は★ごとに残る。続けて同じ事件名は出ない
- 難問: 容疑者9人・★3 の事件（練習）。Web Worker で作り（使えない環境では画面側で作る）、カードをつめた盤面と名簿（押すとそのカードへ）で遊ぶ
- 事件簿: 直近14日の日替わり事件。過去の日も遊べる（連続日数には数えない）。解決数・連続・最高連続・ノーミス数
- 結果: 「解決」の判子の演出、称号、時間・ミス・ヒント、提出の記録（□□■。多いときは「□×n ■」）、解いた時点の連続日数
- 結果の共有: 1080×1350 の画像（答えと村人の名前は描かない）。スマホは OS の共有、PC と共有できない環境は画面内に画像を出し［X に投稿］［共有…］［結果をコピー］［画像を保存］。結果の文のコピー
- スマホの「戻る」でアプリ内の前の画面へ戻る。別のタブや PWA と同時に開いても、ほかで付けた記録を上書きしない
- 設定: 効果音・振動の ON/OFF、テーマ（自動 / ライト / ダーク）、記録の消去（画面内で2段階の確認）。iOS アプリは毎朝の通知（時刻を選べる）と夜の念押し（20:00）
- PWA: ホーム画面に追加でき、一度開けば通信なしで遊べる（`sw.js`）。iOS アプリと Claude Artifact の中では Service Worker を登録しない
- iOS アプリ（Capacitor 7）: 触覚・ローカル通知・共有シート・記録の二重保存・状態バーの文字色をテーマに合わせる
- 効果音は WebAudio でその場で作る（音声ファイルなし）。アイコン・似顔絵（16人）・判子はすべて SVG

## テスト

推論エンジンを直したら、必ず次を実行する（要 Node.js。ほかに入れるものは無い）。

```bash
node tools/check-engine.mjs index.html
```

- `index.html` からエンジン部分だけを取り出し、★×人数ごとに問題を作って検査する（3〜6人は各200問、7〜9人は各100問、日替わりは 2026-10-01 から120日分）
- 答えが1つに決まるか（総当たり）、解説の各手順が論理的に正しいか、★の判定、答え合わせ・ヒントの動き、同じ日付で同じ問題になるか、事件名の割り当て、文章に `undefined` などが混ざらないか、生成の速さ、Web Worker の中で動くかを確かめる
- 3〜6人の問題が変わっていないかの回帰テストもある（日替わり365日・練習240問のハッシュ）
- 最後に `PASS` / `FAIL` を出す。FAIL があれば終了コード 1。2026-10-08 時点で全64項目 PASS（約9秒）
- 問題の作り方を変えると、全員の日替わり問題が変わる。そのときはエンジンの `VERSION` を上げ、docs に記録する（版が変わると、解きかけの判定は使わずにやり直しになる）

## ローカルでの確認

```bash
python3 -m http.server 8793 --bind 127.0.0.1
```

このフォルダで実行し、http://127.0.0.1:8793/ を開く（`.claude/launch.json` と同じ設定）。
Claude がブラウザで触るときは、先に音を消す（[../_テンプレート/動作チェックのミュート手順.md](../_テンプレート/動作チェックのミュート手順.md)）。
ローカルでも Service Worker が登録される。確かめ終わったら、開発者ツールで登録を解除しておくと紛らわしくない。
