# サポートページの「ミスの数え方」の説明を実際の動きに合わせる

- 管理番号: #0014
- 種類: FIX（軽微な修正）
- 対象: PWA と公開用の素材（`support.html`）
- 作成日: 2026-10-09
- 関連: #0005（サポートページ）、#0016（点検の報告。指摘 #41）

## 概要

`support.html` のよくある質問「ミスやヒントはどう数えますか」に「同じ答えをもう一度出すことはできないので、二重には数えません」とあった。実際のアプリが止めるのは**直前に違っていた答えと同じ答え**だけで、A（誤り）→ B（誤り）→ A と出すと、A のミスは2回目も数える。#0001 の仕様（「違っていた答えと同じあいだは提出できない」）とアプリは合っていて、食い違っていたのはサポートページの文だけなので、文を直した。

## 対象ファイル

- `support.html`

## 変更内容

「同じ答えをもう一度出すことはできないので、二重には数えません。」→「直前に違っていた答えと同じままでは提出できないので、続けて二重に数えることはありません。」

アプリ（`index.html`）は変えていない。出した誤答を全部覚えて止める作りにすると保存の形も変わるので、今回はしない。

同じ点検で挙がった「『iOS アプリ版は準備中です』を審査・公開に合わせて直す」は、公開に合わせた書き換え（別の候補）でまとめて扱う。

## 確認

- `support.html` の該当の文が変わったことを確かめた（ほかの文は変えていない）
- `support.html` は Service Worker が先にキャッシュするが、ページはネット優先なので、公開すれば次に開いたときに新しい文が出る（`sw.js` の版は上げなくてよい）
