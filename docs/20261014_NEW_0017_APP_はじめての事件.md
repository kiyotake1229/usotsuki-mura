# はじめての事件（3問の案内つき練習）

- 管理番号: #0017
- 種類: NEW（新規開発）
- 対象: アプリ本体（APP）
- 作成日: 2026-10-14
- 関連: #0018（今週の難問）・#0019（事件簿の全日表示）と同じコミット、#0001（冒頭の「このあとの変更」に追記）、README「今後の候補」の「初めて遊ぶ人への案内」

## 概要

初めて遊ぶ人のための、案内つきの3問「はじめての事件」を足した。第1話で判子の押し方、第2話で1人わかると次の人がわかる「つながり」、第3話で「もし嘘つきだったら」と仮に決める考え方を、盤面の上の案内を見ながら順に練習する。ミス・ヒント・時間・解決数・連続日数には数えない。推論エンジンは変えていないので、日替わり・練習・難問の問題は1つも変わらない（`VERSION` は 3 のまま）。

## 対象ファイル

- `index.html`（画面の HTML・CSS・JavaScript。新しい目印 `// ==TUTORIAL START==`〜`// ==TUTORIAL END==`、保存の目印 `// ==STORE START==`〜`// ==STORE END==`）
- `tools/check-app.mjs`（はじめての事件の検査を追加）
- `support.html`（遊び方に「はじめての事件」、よくある質問「はじめて遊びます。何から始めればいいですか」、プライバシーポリシーの保存する情報）
- `ios-app/岩崎さんへの引き渡し手順.md`（申請の説明文・プロモーション用テキスト・審査用の遊び方）

## 変更内容

### 1. 3話の問題（固定）

| 話 | 練習すること | 問題 | 中身 |
|---|---|---|---|
| 第1話 | 判子を押してみよう | `Engine.generate({ seed: 'tut1-12350', people: 3, star: 1 })`「消えたはちみつのつぼ」 | 3人・★1。メモから4手（仮定なし） |
| 第2話 | つながりをたどる | `Engine.generate({ seed: 'tut2-148489', people: 4, star: 1 })`「風見鶏に乗った村長の帽子」 | 4人・★1。メモから5手。上から順には進まず、「同じ側」を使う |
| 第3話 | 仮定を置く | `Engine.example()`（遊び方の例題と同じ「消えたクリームパン」） | 4人・メモなし。最初の一手が仮定1回 |

- 3話の表（seed・ハッシュ・案内の文）と `tutorialPuzzle(ep)` は `// ==TUTORIAL START==`〜`END` の間に置いた。エンジンだけを使うので、`check-app` が取り出して確かめる
- 第3話は例題のパン屋のアオイが、自分の店のパンの事件の犯人になる。画面に出す**あらましの文だけ**「村の朝市の屋台から、焼きたてのクリームパンが消えた。…」に替えた（問題そのものは変えていない）
- 3話の顔ぶれ（11人）はすべて別人
- エンジンの作り方が変わる（`VERSION` を上げる）と、同じ seed でも別の問題になる。そのときは `check-app` のハッシュ（各話と、3話まとめた `44d921d9…`）が FAIL するので、seed を選び直して案内の文も直す

### 2. 事件の画面

- 盤面の上に「第N話で練習すること」の枠（その話の説明）と、**案内の枠**を出す。案内の枠は下へ読み進めても上に付いてくる。判子を押すたび・誤答のたびに中身が変わる
  - 案内はエンジンのヒント（`Engine.hint`）が返す「次の手順」に合わせて、手順ごとに用意した文を出す（`tutGuide`・`renderGuide`）
  - 案内の中の名前を押すと、その人のカードへ移動する（`nameLinks`）
  - 間違った判子のときは「〇〇の判定を見直してみよう」に、考え方を添える（例「スズは正直者なので、『ナギは嘘つきだよ』は本当。」）。第1話では「［嘘つき］を押せば付け替えられます」、犯人のときは「ほかの人のカードで押せば」と添える
- 第3話（仮定）は、案内どおりにイツキの［嘘つき］を仮に押すと、仮定のままたどる案内に切り替わる
  - 仮定と逆の判子を押すと「仮定のままだと、エマは嘘つきです」のように知らせる（犯人を別の人にしたときも同じ）
  - 仮定どおりにそろうと「仮に押した判子がそろいました。［推理を提出］で、食い違いが出るか確かめましょう（ここではミスに数えません）」
  - 提出して食い違うと「食い違いが出ました。つまり『イツキは嘘つき』が間違いです。イツキを正直者にして、たどり直しましょう」。同じ判子に押し直したとき・開き直したときも、この案内を出す
- はじめての事件では「きまり」の箱を出さない（練習することの枠と同じ文になり、最初の一手が画面の下へ押し出されるため）。「犯人は1人」は練習することの文に入れた。あらましは最初からたたむ
- **数えないもの**: ミス・ヒント・時間・解決数・練習の解決数・連続日数。画面上部の時間とミスも隠す
- 上部の名前・結果の判子の周りの文字は「はじめての事件 第N話」

### 3. 解いたとき

- 結果は「第N話 解決」と、その話のまとめの一文、3話の進み具合、［第N+1話へ］
- 3話目のあとは「これで準備は完了です」と曜日ごとの難しさの説明、［今日の事件を開く］
- 第3話の締めに「本番では、食い違いを頭の中で確かめてから提出すると、ミスになりません」
- 解説の画面の［次へ］も同じ行き先（`nextCase`・`nextLabel`）

### 4. 入口

- **ホーム**: 今日の事件の上に「はじめての方へ」のカード（3問・約5分、進み具合、［はじめる］／［第N話から続ける］、×で閉じる）
  - 出す条件（`showTutCard`）: 閉じていない、3話とも解いていない、かつ「まだ1件も解いていない人（日替わり・練習・今週の難問のどれも）」か「はじめての事件を進めている人」
  - 今日の事件を開いただけでは消えない（審査の人が今日の事件を開いてホームに戻っても出たまま）
- **遊び方**: いちばん上に「はじめての事件」の枠。ボタンは進み具合で変わる（［はじめての事件で練習する］／［第N話から］［最初から］／［もう一度練習する］）。読み上げ用の名前は「第N話から続ける」。320px 幅でも1行に収まる
- 遊び方の例題の［考え方と答えを見る］のすぐ上に「はじめての事件の第3話と同じ問題です。先に自分で解きたいときは、答えを開かずに第3話へ。」

### 5. 保存（`usotsuki.v1`。形の v は 1 のまま）

- `tutorial: { done: 0〜3（解いた話の数。いちばん進んだ所）, dismissed: true/false（ホームの案内を閉じた）, cur: { ep, 判子…, v } | null（途中の話）}`
- 途中は判子だけ残す（読み込み直しても続きから再開できる）。解いたら途中を消して `done` を進める
- 読み込み（`sanitize`）で `tutorial` を残す。壊れた値（文字・範囲外の話数・型違いの途中）は既定に戻し、ほかの記録は消さない
- 古い版のタブが同時に開いていて `tutorial` の無い保存を書いた場合は、記録を消した回（`epoch`）が同じなら戻す（`carryNew`。`update` と別タブの読み直しの両方で効く）
- 「記録を消す」で一緒に消え、ホームの案内がまた出る。確認の文は「日替わりと今週の難問の記録・練習の途中・連続日数・はじめての事件の進み具合をすべて消します。」

### 6. 新しい関数

`tutGuide`・`renderGuide`・`openTutorial`・`tutNext`・`tutStarted`・`showTutCard`・`renderTutCard`・`tutStepsHTML`・`renderHowtoTut`・`tutResultHTML`・`nameLinks`。共通: `nextCase`・`nextLabel`・`topLabelOf`・`carryNew`（［次の事件］の3か所は `nextCase` を通す）
