## 直さなかったもの・理由

- **お問い合わせのメールアドレス**（レビュー 9）: どのアドレスを一般公開するかは清武さんが決めること。決まったら `support.html` の「お問い合わせ」とプライバシーポリシー7章に足す。App Store の審査で連絡手段の不足を指摘されたら、このときに足す
- **リポジトリを公開にするか**（レビュー 8 の残り）: GitHub Pages の公開サイトでは `_config.yml` で隠したが、公開リポジトリでは docs/（工数・社内の段取り）と引き渡し手順（上長の名前）が読める。ほかのアプリ（語彙力など）も同じ形で公開している。隠すなら、リポジトリを private にして公開用のファイルだけを Pages に出す（GitHub の有料プランか、Actions で必要なファイルだけ配る形）か、docs/ を別の非公開リポジトリに分ける。清武さんの判断が要る
- `.nojekyll` を置く場合: ほかのアプリは `.nojekyll` を置いている。このアプリで置くと `_config.yml` が効かず、docs/ などが公開サイトでも開けるようになる。置かないこと
- Claude Artifact への公開し直し: この作業ではしていない（https://claude.ai/artifact/BRWf8oJikTLt1mrkdA83Di は 2026-10-08 朝の版のまま）

- `ios-app`: `npm install`（status-bar 追加）→ `npm run sync`: pod install まで成功（最後の `xcodebuild clean` だけ Xcode が無いため失敗。#0006 と同じ想定どおり）。そのあと `node_modules/` と `ios/App/Pods/` は消した。手で直した `Info.plist`・Bundle ID・iPhone 専用・`PrivacyInfo.xcprivacy` の登録は残っている
- 確認のあと: アプリ内の Browser の記録（localStorage）は確認前の値（679文字）に戻し、画面の幅は desktop に戻した。Service Worker は確認前も登録されていたので登録したまま（新しい `sw.js` の v2 に入れ替わり、v1 のキャッシュは消えた）。確認用の Chrome と操作の道具は止め、Chrome の一時プロファイルは消した

**まだ確かめていないこと**: スマホ実機（iPhone Safari・Android Chrome の Web Share、ホーム画面に追加、オフライン）、Xcode でのビルドと実機の状態バーの色（GitHub Actions の「iOS build check」は push 後）、実際の Claude Artifact での動き。
