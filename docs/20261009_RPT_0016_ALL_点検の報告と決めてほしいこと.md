## 決めてほしいこと（清武さん）

### 1. 問い合わせ用のメールアドレス（指摘 #3・App Store 申請を止める項目）

サポートページの連絡先は GitHub の Issues だけ（書き込むには GitHub のアカウントが要り、内容は公開される）。App Store の審査ガイドライン 1.5 は「開発者へ簡単に連絡できる手段」を求めるので、メールの連絡先を足したい。個人のアドレスは避け、`ltv.work` のサポート用（例: support@ltv.work）がよい。決まったら次を行う。

- `support.html` の「お問い合わせ」の Issues の上に、メールのカード（`mailto:アドレス?subject=` に件名「嘘つき村の事件簿」を URL エンコードしたもの。SVG アイコン。説明は「メール（アカウント不要・内容は公開されません）」）を足し、Issues は「GitHub をお使いの方は」という扱いにする
- プライバシーポリシー7章にも同じアドレスを書く
- #0007 の「直さなかったもの」と README の残作業を更新し、FIX か ENH で記録する
- `support.html` はページなので、`sw.js` の版は上げなくてよい（ネット優先で届く）

### 2. 公開リポジトリに社内の文書を置いてよいか（指摘 #35）

リポジトリ `kiyotake1229/usotsuki-mura` は public。公開サイト（GitHub Pages）では `_config.yml` で隠しているが、github.com のリポジトリでは `資料/`（社内説明の台本・スライド・PDF。上長の名前や社内の段取り、費用の話を含む）、`docs/`（工数や手元のパスを含む）、`ios-app/岩崎さんへの引き渡し手順.md` が誰でも読める。2026-10-09 時点で fork・star は 0。

- 案A: リポジトリを private にし、公開用のファイル（`index.html`・`sw.js`・`manifest.json`・アイコン・`ogp.png`・`support.html`・`_config.yml`）だけを別の public リポジトリに出す（private のまま Pages を使うには有料の GitHub Pro が要る）
- 案B: `資料/`・`docs/`・引き渡し手順を追跡から外して `.gitignore` に足し、別の private リポジトリか Dropbox だけで管理する
- どちらでも過去の履歴には残る。完全に消すには履歴を書き換えて force push する必要があり、**取り消せない**ので、実行の前に確認する

### 3. UIScene への対応のしかた（指摘 #36・2027年4月まで）

当面は Xcode 26 でビルドする（#0015）。2027年4月ごろ申請に Xcode 27 が必須になる前に、どちらかで UIScene に対応する。どちらも、Xcode とシミュレータでの起動の確認が要る。

- 案A: Capacitor 7 のまま、`Info.plist` に `UIApplicationSceneManifest` を足し、`SceneDelegate.swift`（URL を開く・ユニバーサルリンクを `ApplicationDelegateProxy` に渡す）を作って登録する。変更は小さい
- 案B: Capacitor 8.5 以降に上げて `npx cap migrate` を流す。最小 iOS 15・プラグインの一斉更新を伴う
- どちらでも、CI に Xcode 27 でのビルドと、シミュレータでの起動（数秒後もプロセスが生きているか）の確認を足す
- **時期を早める必要があるかもしれない**（直したあとの確認で追記）: Apple の対応表では、Xcode 26.x が動く macOS は「Tahoe 26.x まで」で、macOS 27 は入っていない（#0015 の4章）。この Mac も macOS 27.0.1。岩崎さんの Mac が macOS 27 なら、Xcode 26 でビルドできず、UIScene に対応して Xcode 27 でビルドするしかない。引き渡しの前に岩崎さんの Mac の macOS を確かめ、27 なら UIScene への対応を引き渡しより先に行う

### 4. 日付を大きく戻して解いたときの連続日数（#0010 の直したあとの確認）

時計を先の日付にして解いたあと戻すと、連続が何か月も増えなくなる不具合を直すため、日付が戻っても連続を巻き戻さない守りを「時差の幅（2日）」に限った（#0010 の3章）。そのため、時計を1か月戻してその日の事件を解くと、連続は1日目からになる（最高連続は残る。解かずに戻せば連続はそのまま）。「先へ進めて戻す」と「大きく戻して解いて元に戻す」の両方で連続を守るには、日替わりの記録（解いた日の一覧）から連続を数え直す作りに変える必要がある。今の形でよいか、清武さんに決めてほしい。
