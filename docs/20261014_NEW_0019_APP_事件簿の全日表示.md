# 事件簿の全日表示（毎日の事件・今週の難問の切り替え）

## 概要

事件簿を「直近14日」から、No.1（2026-10-01）から今日までの**すべての日**に広げた。「毎日の事件／今週の難問」の切り替えを付け、過去の週の難問も事件簿から遊べるようにした。日数が増えても重くならないよう、最初は30行だけ描き、「もっと見る」で60行ずつ足す。推論エンジンは変えていない（`VERSION` は 3 のまま）。

## 対象ファイル

- `index.html`（画面の HTML・CSS・JavaScript。並びの関数は `// ==DAYRULES START==`〜`END`）
- `tools/check-app.mjs`（事件簿の並び・重さの検査を追加）
- `support.html`（よくある質問「前の日の事件は遊べますか」）
- `ios-app/岩崎さんへの引き渡し手順.md`（申請の説明文の「直近14日」の行）

## 変更内容

### 1. 並び（`DAYRULES` に追加。画面の状態に触れないので `check-app` で試せる）

| 関数 | すること |
|---|---|
| `bookDays(今日)` | 今日から No.1 の日まで（新しい順）。端末の日付が No.1 より前なら No.1 の1日だけ |
| `bookWeeks(今日)` | 今週から第1週まで（新しい順。月曜の日付） |
| `bookRows(一覧, from, to, 見出しの決め方)` | from〜to-1 番目を、見出しつきの行にする。前の行と比べて見出しを入れるので、続きを足しても見出しが重ならない |
| `monthOf`・`yearOf` | 毎日の事件は月ごと（「2026年10月」）、今週の難問は年ごと（「2026年」）の見出し |

### 2. 画面

- 合計（解決・連続・最高連続・ノーミス）の下に「練習で解いた事件 N件・今週の難問を解いた週 N週」
- 切り替え（タブ）: 「毎日の事件 14日」「今週の難問 3週」。キーボードでも選べる（`role="tablist"`）
- 毎日の事件の行は今までと同じ（No.・日付・★・人数・「今日」・題名・解決の判子／途中／未解決）。今週の難問の行は「第N週・10/12〜10/18・★3・9人・今週・題名（開いた週だけ）・状態」
- 最初は30行。「もっと見る（あと N日）」で60行ずつ足す（描き直さずに続きを足し、足した最初の行に焦点を移す）
- 別タブの変更などで描き直しても、出している行数と切り替えは保つ。事件簿を開き直したときだけ30行に戻る。過去の日・週を開いて戻ったときも保つ
- 画面の外の行は描くのを後回しにする指定（`content-visibility:auto`）を付けた
- 行の焦点の枠を行の内側に描く（`content-visibility` で行の外が切り取られるため。Tab キーで行に移ると枠が見える）
- ホームの事件簿の入口の説明を「これまでの事件（毎日・今週の難問）と記録」にした
- 説明文の「直近14日」を、アプリ・サポートページ・引き渡し手順から無くした
