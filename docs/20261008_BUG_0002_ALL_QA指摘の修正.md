# QA 指摘の修正（判子が消えない不具合ほか）

- 管理番号: #0002
- 種類: BUG（バグ修正。あわせて改善を含む）
- 対象: 全体（ALL。画面 APP が中心、推論エンジン ENG は日替わりの事件の割り当てだけ）
- 作成日: 2026-10-08
- 関連: #0001（現状の仕様と構成。この修正を反映済み）

## 概要

公開前のブラウザ QA（15件）とコードレビュー（12件）の指摘を確かめて直した。一番大きいのは、判子を外したり付け替えたりしても前の判子が画面に残る不具合（盤面の見た目が答えと食い違う）。ほかに、同じ誤答の二重カウント、過去の結果で連続日数がずれる、別タブでの記録の上書き、スマホの「戻る」など。日替わりの事件の割り当てを変えたので、エンジンの `VERSION` を 2→3 に上げた。

## 対象ファイル

- `index.html`（画面の CSS・JavaScript、推論エンジンの `STORIES` と `storyIndexForNo`、`VERSION`）
- `tools/check-engine.mjs`（検査を1項目追加）
- `README.md`、`docs/20261008_DOC_0001_ALL_現状の仕様と構成.md`（実装に合わせて更新）

## 変更内容

### 不具合の修正

| 指摘 | 直したこと |
|---|---|
| 判子を外す・付け替えても前の判子が残る（重大） | 押す動きの CSS を押されているボタンだけに効かせ、外したボタンからは動きの class を必ず外す。動きが終わったら class を外す |
| 「推理を提出」2回でミスが2回数えられる | 違っていた答え（判定と犯人の組）を覚えて保存し、同じ答えのあいだは提出ボタンを押せなくして「判定を直すと提出できます」と出す。提出後0.5秒は次の提出を受け付けない。結果画面は出てから0.3秒（演出ありは0.7秒）ボタンを受け付けない |
| 名前やヒントで光らせたカードが一瞬消えて登場をやり直す | 登場・揺れ・判子の動きを `animationend` で外す。光らせる前にも外す |
| 過去の結果・コピー文の「連続〇日」が今の値になる | 解いた時点の連続日数を日替わりの記録（`streak`）に保存して使う |
| 別タブ・PWA と同時に開くと記録が消える | 記録を変えるときは保存済みを読み直してから自分の変更だけを重ねる（`update`）。解決済みの日は上書きしない。別タブで先に解いた日は二重に数えない。`storage` イベントで読み直す |
| 同じヒントでも開き直すと回数が増える | 「段｜次に印が付く手順」の組で覚えて保存し、初めての組だけ数える。2段目を見たあとの同じ手順の1段目も数えない。絞り込みの手順（`seenSteps`）も保存する |
| 作り方の版が変わった途中で、ミス・ヒント・時間だけ引き継ぐ | 版が違えばすべて0から。ホームと事件簿でも「未解決」として見せる |
| 保存データの型を確かめていない（`NaN:NaN`、`'1'+1='11'`） | 読み込み時に項目ごとに型を確かめる（数は有限の数か数字の文字列だけ、□■ だけ、テーマは3つだけ など） |
| 表示したまま日付が変わるとホームと事件簿が前日のまま | 0.5秒ごとに日付を確かめ、変わったら描き直す |
| 練習の途中が1つしか残らない | ★ごとに1件ずつ残す（`practice.byStar`。古い形は読み込み時に移す）。手を付けたものだけ「途中」の印 |
| 練習で［盤面を見る］のあと結果に戻れない | 練習の解決後のバーを［解説を見る］［結果を見る］［次の事件］の3つにする |
| 「記録を消す」の確認が開いたまま残る | 設定画面を開くたびに閉じた状態に戻す |
| テーマのボタンのアイコンが背景に溶ける | 行の頭のアイコンだけを薄くする指定に絞る（選ばれたボタンのアイコンは文字と同じ色） |
| ダークで OFF のスイッチのつまみが見えない | OFF のつまみを明るい色に（ライトは枠付きの白）。色は変数 `--knob-*` |
| 「正直者」「嘘つき」・テーマのボタンに焦点の枠が出ない | 枠をボタンの内側に描く |
| 結果が開いても焦点が移らない・テーマ切替で焦点が消える | 結果は見出しに焦点を移し、後ろの画面に `inert`。閉じたら［結果を見る］へ戻す。テーマは押したボタンに焦点を戻す |

### 改善

| 指摘 | 直したこと |
|---|---|
| スマホの「戻る」でアプリから出てしまう | 画面の行き来を `history.pushState` で積む。戻るで前の画面へ、結果やパネルが開いていれば先に閉じる。見出しの戻るボタンも同じ動き |
| 解説の最後に次へ進むボタンが無い | 解説の最後に［事件に戻る］［ホームへ］（練習は［次の事件］も） |
| 練習で同じ事件名が続く | 直前の練習と同じ題名なら seed を変えて作り直す |
| 日替わりで似た題材が近い日に並ぶ（羊・時計など） | 事件に題材 `g` を付け、直前6日に出た事件と店か題材が同じものを外して選ぶ。**日替わりの問題が変わる**: 10-09 以降の事件名と顔ぶれが変わる（365日のうち305日）。10-01〜10-08 の問題は同じ。`VERSION` を 2→3 に上げた |
| 犯人の印と食い違いのカードの色が似ている | 犯人のカードは背景色なし（ボタンの朱の枠と判子だけ）。食い違いは朱の左帯・薄い朱の背景・枠 |
| 1〜2文字だけ次の行に落ちる | 文節で折り返す `word-break:auto-phrase` と `text-wrap:pretty`。ホームの説明文と練習カードは `<wbr>`＋`keep-all`。事件簿の日付の行も途中で切らない |
| 呼び方がそろっていない | 「本日の事件」→「今日の事件」、事件簿の「未着手」→「未解決」、「犯人を1人選んでください」→「犯人を1人選ぶ」 |
| Google Fonts が表示を止める | `media="print"` で読み始めて、読み終わったら切り替える（`<noscript>` は通常の読み込み） |
| 色の直書き | `--on-shu`・`--moon`・`--star-dot`・`--knob-*` を足して置き換え |
| ダブルタップの拡大待ち | ボタンに `touch-action:manipulation` |
| 画面読み上げで判定ボタンが「正正正直者」と読まれる | 判子の絵（`sealBox()` の `.sealbox`）に `aria-hidden="true"`。ボタンは「正直者」「嘘つき」「犯人」とだけ読まれる |

### 直さなかったもの

なし（指摘はすべて対応した）。日替わりは開いただけで「途中」になる点は、時間が進み始めるので今のままにした（練習は手を付けるまで「途中」にしない）。

## 確認

- `node tools/check-engine.mjs index.html`: 全48項目 PASS（約6秒）。追加した検査「日替わり: 店か題材が同じ事件が7日以内に続かない」を含む。生成時間は全体平均 1.5ms・最大 91.8ms。`--days 1100`（約3年）でも全項目 PASS
- ブラウザ（ローカル、http://127.0.0.1:8793/。音は消してから操作）
  - 375px: ハルの［正直者］→［嘘つき］で「嘘」だけ残る、もう一度押すと消える。犯人の付け替えで前の「犯」が消える
  - 375px: 誤答で［推理を提出］をダブルタップ → ミス1・□。ボタンは「判定を直すと提出できます」。リロード後も同じ。直して提出 → 正解、2回目のタップで結果が閉じない
  - 同じヒントを開き直しても回数が増えない（リロード後も）
  - 過去の日（連続3日で解いた記録）の結果に「連続 3 日」。壊れた値（`elapsed:'abc'` など）でも 0:00 と表示
  - 練習 ★3 に印を付けて戻る → ★1 を開いて戻る → ★3 に「途中」が残り、続きから開ける
  - 練習の解決後のバー3つ（360px でもはみ出さない）、解説の最後のボタン、［次の事件］で別の題名
  - 戻る（ブラウザの履歴）: 解説→事件→（結果を開いた状態では結果だけ閉じる）→ホーム
  - 別タブを想定し、保存済みの記録を外から書き換えた状態でこちらの保存を走らせても、外の解決・連続日数が残る。別タブで解いた日をこちらで解いても二重に数えない
  - 設定: 記録を消す確認が開き直すと閉じている。ダーク・ライトでテーマのアイコンとスイッチの OFF が見える。キーボードの Tab で［嘘つき］に内側の枠
  - 通し（360x740）: 今日の事件を1回間違えてから解く → 結果をコピー（この環境ではクリップボード不可のため、文字を選んだ状態の表示に切り替わる） → 解説 → 事件簿 → 練習★3を1問 → 設定でダーク。コンソールのエラー0件、横スクロールなし
  - PC幅: 中央 480px の列
- 確認に使った記録は消した
- 2026-10-08 に Claude Artifact で公開した。Claude の確認用ブラウザは claude.ai にログインしていないため、公開ページそのものは開けていない。代わりに、外から読むのが Google Fonts だけで、Artifact で止められる読み込み（fetch・Worker など）を使っていないことをコードで確かめた。スマホ実機での確認はまだ
